# Uni Finder 🎓

A university search and comparison tool that lets you filter universities by country, subject, ranking, and more.

## Features
- Search universities by name or country
- Filter by subject area
- Clean card-based results UI
- Fast client-side filtering

## Tech Stack
- HTML / CSS / JavaScript (Vanilla)
- University API / static dataset

## Getting Started

```bash
git clone https://github.com/RiyanMujtaba/uni-finder
```

Open index.html in your browser. No server required.
